# 常见问题说明
## 本体配置话题
### 对于内嵌力控的机器人，如何配置负载？
SDK中涉及负载的配置有两个接口
* ``robot_set_tool_payload``: 任何机器进行负载配置，该接口会自动将负载信息发送给机器人，机器人会根据负载信息进行转矩前馈和碰撞检测的修正。需要注意请在机器人静止状态下进行配置

* ``robot_set_ftsensor_payload``:用于外置力传感器的机器进行负载配置，内嵌力传感器的机型（如ZY620,K15020，S系列等）不能使用该接口进行配置，否则会影响负载。

## 整机系统话题
### 关机接口逻辑？
``shut_down``

> 注意：期间禁止其他接口调用，且保持控制柜供电，否则会有概率导致文件系统损坏，用户配置丢失

1. Step1：关闭本体使能，耗时1s
2. Step2：关闭本体电源，耗时1s
3. Step3：保存系统所有参数,关闭应用服务，耗时1~2s。此时会SDK会断开连接
4. Step4: 操作系统关机，耗时1～2s
